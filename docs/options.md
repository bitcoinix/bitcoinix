# Module options

These are the options of the bitcoinix modules in this release, with their types,
defaults and examples. Filter the list by name or description in the field below,
or use the search in the menu bar to search the whole documentation. The NixOS
options are in the [NixOS options search](https://search.nixos.org/options).
