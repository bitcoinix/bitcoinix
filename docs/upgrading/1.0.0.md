# Upgrading to config version 1.0.0

TBD. The upgrade notes will be consolidated here for the 1.0.0 release.

While 1.0.0 is in development, keep `bitcoinix.configVersion` at the latest finalized release.
After migrating to the finalized release, set `bitcoinix.configVersion = "1.0.0";`.

See the [draft upgrade notes on GitHub](https://github.com/bitcoinix/bitcoinix/tree/master/docs/upgrading/1.0.0).
