# Upgrading to config version 0.2.1

TBD. The upgrade notes will be consolidated here for the 0.2.1 release.

While 0.2.1 is in development, keep `nix-bitcoin.configVersion` at the latest finalized release.
After migrating to the finalized release, set `nix-bitcoin.configVersion = "0.2.1";`.

Drafts will appear under `0.2.1/` in the [upgrade notes directory on GitHub](https://github.com/bitcoinix/bitcoinix/tree/master/docs/upgrading).
