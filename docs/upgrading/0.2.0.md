# Upgrading to config version 0.2.0

TBD. The upgrade notes will be consolidated here for the 0.2.0 release.

While 0.2.0 is still in development, keep `nix-bitcoin.configVersion = "0.1.6";`.
Once the release is finalized, review its migrations, then set
`nix-bitcoin.configVersion = "0.2.0";`.

See the [draft upgrade notes on GitHub](https://github.com/bitcoinix/bitcoinix/tree/master/docs/upgrading/0.2.0).
