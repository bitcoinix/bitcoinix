# Release notes

For configuration migrations reported during evaluation, follow the
[upgrading guide](upgrading.md).

During development, each change has its own file under `docs/release-notes/<version>/`.
At release time, the draft files are combined into `docs/release-notes/<version>.md`.
See [Cutting a release](https://github.com/bitcoinix/bitcoinix/blob/master/dev/README.md#cutting-a-release).
