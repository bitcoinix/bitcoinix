#### .NET 10.0.15 for BTCPay Server and NBXplorer

The nixpkgs update moves BTCPay Server and NBXplorer to the .NET 10.0.15
runtime, a [security release](https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.15/10.0.15.md)
that fixes several ASP.NET Core denial of service, elevation of privilege and
information disclosure vulnerabilities. Their versions stay at 2.4.7 and 2.6.17.
