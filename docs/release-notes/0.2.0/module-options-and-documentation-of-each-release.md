#### Module options and documentation of each release

The new [module options](../../options.md) page lists the options of the bitcoinix
modules with their types, defaults and examples, and can be filtered. It replaces
the search.nixos.org links, which mixed in options of other flakes.
docs.bitcoinix.net serves the latest release at its root, as before, and keeps the
documentation of each release from 0.1.6 on at `/v/<version>/`, for example
`https://docs.bitcoinix.net/v/0.1.6/`. A selector in the menu bar switches between
releases.
