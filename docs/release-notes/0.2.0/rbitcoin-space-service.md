#### rbitcoin.space service (experimental)

New service: [rbitcoin.space](../../services.md#rbitcoinspace) 0.4.0, a block explorer for
rbitcoin with a live mempool, projected blocks, mining pages and an Esplora-compatible
API. Enable it with `services.rbitcoin-space.enable = true;`. It enables rbitcoin with
its RPC, Electrum and Esplora servers. `services.rbitcoin.esplora` is new and serves
rbitcoin's Esplora REST API on port 3002.
